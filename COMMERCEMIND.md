# CommerceMind AI

Enterprise AI-Powered E-Commerce Platform built on Medusa.js v2, featuring autonomous business intelligence, multi-provider AI analysts (Ollama, OpenAI, Claude, Gemini), and a high-performance Next.js storefront.

## Architecture

- **Commerce Engine**: Medusa.js v2 (100% upgrade-safe, zero core modifications)
- **AI Gateway Module**: Custom Medusa Module routing requests between local Ollama instances and cloud LLMs.
- **BI & Analytics**: Executive dashboards, real-time KPI metrics, demand forecasting, and inventory optimization.
- **Storefront**: Next.js 15, Tailwind CSS, Shadcn UI with Apple/Stripe-inspired design.

## Features

- **AI Business Intelligence**: Automated analysis of sales, inventory, marketing, and customer metrics.
- **Multi-Model Support**: Seamless switching between Ollama (Llama 3, Qwen, DeepSeek) and Cloud AI providers.
- **Enterprise Commerce**: Powered by Medusa.js v2 modular architecture.
